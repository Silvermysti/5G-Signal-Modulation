Project report · RadioML 2018.01A

Teaching a CNN to recognize radio signals — a scaled-down replication

We rebuilt the VGG-style convolutional network from O'Shea, Roy & Clancy's Over the Air Deep Learning Based Radio Signal Classification, shrunk from 24 modulations to 3 so it trains on a CPU laptop in minutes — then dug into why it scores what it scores.

2026-07-20 Silvermysti/5G-Signal-Modulation TensorFlow 2.21 · Keras 3.14 · CPU only
Test accuracy 81.1% 3,000 held-out examples
Cleaner 60% of signals 99.4% matches the paper's high-SNR result
Noisiest 30% ≈42% random guessing = 33%
Model size 158,915 parameters · ~621 KB

The headline finding: the flat "81%" hides two very different regimes. On signals clean enough to carry information, the model is essentially perfect (~99%). On the noisiest third, the modulation is physically destroyed by noise before it reaches the receiver — no classifier can recover it. This isn't a model weakness; it's an information limit, and it's exactly the S-curve the paper reports.

01 · The task

What the model has to do

Radio transmitters encode data by shaping a carrier wave — a scheme called a modulation. Given a raw 1024-sample I/Q snippet (two channels describing the wave's amplitude and phase over time), the model must name the scheme that produced it. The full DeepSig dataset covers 24 modulations across 2.55 million examples (~19.5 GB); we scoped down to three that are physically distinct, as an encouraging first build:

ClassFull nameHow it carries data
OOKOn-Off Keyingswitches the carrier on and off — the simplest digital scheme
QPSKQuadrature Phase-Shift Keyingjumps between four phase angles
FMFrequency Modulationbends the carrier's frequency continuously (analog, like FM radio)

Following the paper's core thesis, the network sees raw I/Q samples only — no Fourier transform, no hand-crafted features. The network learns its own features from the waveform.

03 · Architecture

Small filters, stacked deep

The VGG idea: instead of a few wide filters, stack many size-3 filters and halve the signal after each with max-pooling. Depth grows the effective field of view — by layer 7 each filter effectively spans a quarter of the original signal — while keeping parameters low.

StageLayersOutput length
Input1024 time-steps × 2 channels (I/Q)1024
Blocks 1–7each: Conv1D(64, size 3, ReLU) → BatchNorm → MaxPool ÷2512 → … → 8
Flatten8 × 64 → one vector512
ClassifierDense 128 (SELU) → Dense 128 (SELU), AlphaDropout128
OutputDense 3, softmax → probabilities3

158,915 parameters total — comparable to the paper's 257k (the difference is almost entirely the narrower output head).

06 · The noise investigation

Recovering the paper's S-curve without SNR labels

The paper insists accuracy be reported as a curve against signal-to-noise ratio — but our three data files don't store the per-example SNR. So we estimated it blind, from the signal alone, using two independent statistics:

  • Spectral flatness — pure noise spreads energy evenly across all frequencies; a real signal has peaks and structure.
  • Lag-1 autocorrelation — noise samples are independent; a real signal is smooth, so neighboring samples relate.

Computed in completely different ways, the two proxies agree with a correlation of −0.996 — strong evidence both measure the same underlying thing: noise level.

Why not feed the SNR estimate back into the classifier? Because there's no headroom: wherever the signal is detectable at all, the model is already at ~99%. The remaining errors live where modulation information is physically absent — destroyed by noise before capture. The estimate's real value is as a gate: answer confidently on the clean ~70%, and honestly say "unknown" on the rest.

08 · Next

Open threads

  • Build the ResNet — skip connections are the paper's best model and the one concept not yet built; same data, same training script, new model function.
  • A "refuse to answer" gate — use the noise proxy to answer only when the signal is classifiable: ~99% accuracy on everything answered.
  • The harder trio — BPSK / QPSK / 8PSK differ only in phase-angle count; a genuine test of whether the network learns phase structure.
